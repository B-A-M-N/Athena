# Visual references

`AthenaBOX.png` is the machine/chassis reference and `DAGOAL.png` is the
computational-display reference. They are the canonical bitmap inputs for the
visual convergence contract in [`docs/VISUAL_CONVERGENCE.md`](../docs/VISUAL_CONVERGENCE.md).

Files named `Screenshot from *.png` are disposable review captures and are
ignored. `ui-reference/` is only a local compatibility alias to these files;
it is not a second source of visual truth.
